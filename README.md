🌐 CCNA Lab Topologies

A collection of networking labs, topology designs, configurations, and practical experiments developed during my CCNA learning journey.

This repository documents my hands-on practice in network design, routing, switching, network services, and enterprise networking using Cisco Packet Tracer and EVE-NG.

🎯 Objectives

- Develop practical networking and troubleshooting skills.
- Understand routing and switching protocols.
- Design and implement enterprise network topologies.
- Practice network segmentation and IP addressing.
- Document configurations, testing procedures, and troubleshooting experiences.


Projects will be added as they are developed and tested.

🧪 Lab Documentation

Each project aims to include:

- README.md: Project overview and objectives.
- Topology Diagram: Visual representation of the network.
- Packet Tracer / EVE-NG File: Working lab topology.
- Configurations: Router and switch configurations.
- Testing & Verification: Connectivity tests and command outputs.
- Troubleshooting: Problems encountered and their solutions.

📚 Learning Resources

This repository is part of my ongoing CCNA preparation and practical networking development.

The focus is on learning by doing, experimenting with network configurations, troubleshooting connectivity issues, and understanding how real-world networks operate.
